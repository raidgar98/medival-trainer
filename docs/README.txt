DYNASTY TRAINER @VERSION@
In-game trainer menu for Medieval Dynasty (singleplayer). UE4SS Lua mod.

Press F4 in game to open the menu (key can be changed in Settings to F2, F11
or End). The menu does not open during conversations or while a game window
(inventory, trade, map...) is open.

TABS
  Player     - unlimited health / stamina, no hunger / thirst, no poison,
               intoxication or dirt, unlimited carry weight, cold and heat
               protection, heal, max health +25%, age, skill points and levels
  Inventory  - add coins, add any item (searchable list with game names)
  World      - time of day, skip day / season, stop time, game speed,
               dynasty reputation, technology points, villager limit,
               max skills of all villagers, max affection of the nearest
               villager, call the king's herald now or next season
  Movement   - speed / jump / gravity multipliers, flying, no clip, field of
               view, teleport to villages, save / return to a position
  Settings   - language (18 languages, same as the game), menu key,
               diagnostics file

NOTES
  - Singleplayer only. Not tested and not intended for co-op.
  - Toggles and multipliers are not saved; they reset when you restart.
  - The villager limit override lasts until the game is restarted.
  - Values you add (coins, items, skills, reputation, technology, age) become
    part of your save when you save the game. Back up your saves.
