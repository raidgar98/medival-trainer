Description

Dynasty Trainer is an in-game trainer menu for Medieval Dynasty (singleplayer). Press F4 in game and a menu opens on the left side of the screen.

  • Plain UE4SS Lua scripts - no .exe, nothing hidden. You can read every line (source on GitHub).
  • Uses the game's own variables and functions instead of memory hacks, so it keeps working while the game runs normally.
  • Works on Windows and on Linux / Steam Deck (Proton).
  • 18 languages - the same languages as the game.

Installation instructions

Easiest - Bundled file (contains UE4SS, ModMenu and the trainer):

  1. Steam > Medieval Dynasty > Manage > Browse local files.
  2. Extract DynastyTrainer-1.0.0-Bundled.zip there and merge the Medieval_Dynasty folder.
  3. Load a save and press F4.

Do not use the Bundled file if you already have UE4SS installed - it would overwrite your UE4SS settings. Use the regular file instead:

  1. Install UE4SS into Medieval_Dynasty\Binaries\Win64 and set EngineVersionOverride to 4 / 27 / false in UE4SS-settings.ini.
  2. Extract ModMenu.zip into Win64\ue4ss\Mods.
  3. Extract DynastyTrainer-1.0.0.zip into the game folder and merge folders.

Linux / Steam Deck: add this to the game's Steam launch options: WINEDLLOVERRIDES="dwmapi=n,b" %command%. On the Steam Deck bind F4 to a button in Steam Input. More in LINUX-STEAMDECK-PROTON.txt inside the archive.

Main features

Player

  • Unlimited health (the game's own GodMode flag), unlimited stamina
  • Never hungry, never thirsty
  • No poison, intoxication or dirt
  • Unlimited carry weight
  • Cold and heat protection (comfortable temperature range)
  • Heal fully, max health +25%, set age
  • Skill points (+10 / +100) and max skill level - per skill or all

Inventory

  • Add coins (quick buttons or any amount)
  • Add any item - searchable list with names in your game language

World

  • Set the hour, skip a day or a season (the game rolls over midnight itself, so daily logic runs normally), stop time, game speed
  • Dynasty reputation +1,000 / +10,000
  • Technology points (Building, Production, Farming, Survival)
  • Override the villager limit (until game restart)
  • Max skills (10) for all villagers of your settlement
  • Max affection of the nearest villager
  • King's herald: call him now with a chosen challenge, or make him come next season

Movement

  • Speed, jump and gravity multipliers
  • Flying and no clip (Space = up, C = down)
  • Field of view
  • Teleport to any village (lands on walkable ground), save / return to a position

Settings

  • Language, menu key (F4, F2, F11 or End), diagnostics file for bug reports

Good to know

  • Singleplayer only. Not for co-op.
  • The menu does not open during conversations or while a game window is open - this protects the dialogue UI.
  • Toggles reset when you restart the game. Things you add (coins, items, skills, reputation...) are saved with your game - back up your saves.
  • Tested on Steam build 25776186 (November 2026). Works together with Dynasty Under Siege Plus, Dynasty Bounty Hunting and Trajectory Preview.
  • Bug reports: please attach ue4ss\UE4SS.log and, if possible, the file from Settings > "Write diagnostics file".

Requirements

  • Bundled file: nothing else needed.
  • Regular file: UE4SS (tested with UE4SS_v3.0.1-1185-gdff435dd) and ModMenu v1.4.0.
  • Keep CheatManagerEnablerMod (part of UE4SS) enabled - flying and no clip need it.
